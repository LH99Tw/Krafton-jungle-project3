# 《5일 뒤 마왕》 문서 인덱스

이 디렉터리는 현재 빌드의 단일 명세 집합이다. 기준일은 2026-08-12, 공용 프로토콜은 v9이다.

## 문서 원칙

1. 코드를 현재 동작의 최종 근거로 삼는다.
2. 섹션마다 명세 문서는 한 장만 유지한다.
3. 구현 완료, 제한, 결함, 계획을 섞지 않고 명시적으로 구분한다.
4. 버전별 변경 문서와 아이디어 초안은 별도 보존하지 않는다. 이력은 Git에서 확인한다.
5. 수치나 계약을 바꾸는 PR은 코드와 해당 명세를 함께 수정한다.
