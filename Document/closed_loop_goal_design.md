# 🎯 로그라이트 클로즈드 루프(Closed-Loop) 목표 설계서

> **목적**: 3일 개발 미니 프로젝트에 가장 적합하면서도 플레이어의 지속적인 도전 욕구를 자극하는 클로즈드 루프(Closed-Loop) 승리/패배 조건 및 게임 목표 비교/설계.

| :--- | :--- | :--- | :--- |

## 2. 세부 모델 분석

### 🧟 모델 1: 카운터스트라이크 온라인 '좀비 쉘터' 방식 (보스 토벌형)

```
[Day 1~4: 기지 구축 & 자원 루팅] ──> [Day 5: 쉘터 급습 보스 등장] ──> [보스 처치 = 승리]
                                                │
                                                └──> [코어 파괴 = 실패]
```

* **메커니즘**:
  - 플레이어는 한정된 일수(예: 5일) 동안 자원을 긁어모아 기지를 최고 수준으로 강화해야 함.
  - 마감 시간(Day 5 밤)이 되면 **최종 보스**가 쉘터를 향해 진격함.
  - 보스는 압도적인 체력과 기지 파괴 능력을 가지고 있으며, 보스를 죽여야만 런(Run)이 승리로 끝남.
* **장점**:
  - 뚜렷한 목표(Target Boss)가 있어 빌드 완성의 명확한 '시험대(Testbed)' 역할을 함.
  - 보스 체력바가 깎이는 시각적 쾌감이 매우 큼.
* **3일 개발 시 위험 요소**:
  - **보스 제작 비용**: 보스 전용 애니메이션, 특수 패턴 AI, 페이즈 변화 구현에 하루 이상의 시간이 소모될 수 있음.

---

### 🍕 모델 2: 프레디의 피자가게(FNaF) 방식 (단계별 7일차 생존형)

```
[Night 1] ──> [Night 2] ──> ... ──> [Night 6] ──> [Night 7 (Final)] ──> [7일 생존 = 승리]
  (입문)       (기믹 추가)             (난이도 피크)     (모든 기믹 총동원)
```

* **메커니즘**:
  - 총 7개의 밤(Night)으로 구성. 하루를 견뎌낼 때마다 **"N일차 생존 성공!"** 연출과 함께 정산 화면 진입.
  - 일차가 지날수록 적의 종류가 추가되거나 공격 경로가 복잡해짐 (Night 1: 단순 멍청이 좀비 $\rightarrow$ Night 3: 자폭 좀비 추가 $\rightarrow$ Night 5: 벽 뛰어넘는 좀비 추가).
* **장점**:
  - **개발 공수가 매우 저렴함**: 보스 그래픽 에셋 없이 적 스폰 데이터/수치 변경만으로 7개 스테이지 구현 가능.
  - **단계적 성취감**: 3일차에 죽더라도 "다음엔 5일차까지 가보자"는 명확한 단계별 목표가 생김.
* **단점**:
  - 마지막 일차(Night 7)의 임팩트가 일반 웨이브와 비슷하면 다소 밋밋하게 끝날 위험이 있음.

---

### 🌟 모델 3 [추천]: 하이브리드 모델 《5 Days to Evacuate (5일간의 탈출)》

> **3일 개발 미니 프로젝트에 가장 최적화된 승리 구조**

```
 ┌───────────────────────────────────────────────────────────┐
 │  Day 1~4 : 단계를 높여가는 웨이브 생존 (FNaF 방식)           │
 │  └─> 밤마다 버티고, 3가지 카드 드래프트로 기지 폭풍 성장       │
 ├───────────────────────────────────────────────────────────┤
 │  Day 5 (Final) : 헬기 구조 요청 & 최후의 방어전 (쉘터 방식)   │
 │  └─> 3분간 쏟아지는 거대 몬스터+폭주 웨이브 버티기            │
 └───────────────────────────────────────────────────────────┘
```

* **핵심 루프 흐름**:
  1. **Day 1 ~ 4 (단계별 서바이블)**
     - 매일 밤(90초)을 생존하면 카드 드래프트 획득.
     - 하루가 끝날 때마다 난이도 레벨 업 & 새로운 적 기믹 해금.
  2. **Day 5 (최후의 탈출 웨이브)**
     - 구조 헬기(또는 탈출 코어) 가동 시작.
     - **3분간 타이머 카운트다운** 시작과 함께 일반 몬스터의 5배 크기인 **'엘리트 보스 몬스터'** 및 대규모 폭주 무리가 몰려옴.
     - 보스를 반드시 죽이지 않아도 **3분간 코어를 지켜내면 탈출(승리)**.

## 3. 리플레이성(Replayability)을 위한 메타 루프 설계

로그라이트 closed-loop의 완성도를 높이기 위해 런 종료(승리/패배) 후 플레이어에게 주어지는 **메타 보상** 구조:

```mermaid
graph LR
    A[게임 런 시작] --> B[생존/방어 도전]
    B -->|승리 or 사망| C[결과 정산]
    C --> D[생존한 일차 기반 '연구 포인트' 획득]
    D --> E[메타 영구 업그레이드]
    E -->|기초 전력 +10, 벽 HP +15%| A
```

1. **영구 업그레이드 (Meta Progression)**:
   - 패배하더라도 도달한 일차(Day)에 비례하여 **'연구 데이터(Research Point)'** 제공.
   - 메인 화면에서 [기초 시작 전력 증가], [벽 초기 내구도 증가], [초기 카드 리롤 횟수 +1] 등 영구 능력치 강화.
2. **해금 요소 (Unlocks)**:
   - 특정 조건 달성 시 신규 타워/카드 해금 (예: *"Day 4 생존 달성 시: 화염방사 타워 해금"*).

## 4. 3일 개발을 위한 스코프 조율 최종 가이드

1. **승리 조건 단순화**:
   - Complex Boss AI 대신 **"3분간 쏟아지는 적 폭주 스폰 + HP가 엄청 높은 엘리트 몹 1마리"**로 Final Wave를 연출하면 보스 AI 개발 시간을 90% 절약할 수 있습니다.
2. **일차(Day) 시간 구성 예시**:
   - **낮 (정비/건설)**: 45초 (또는 플레이어가 'READY' 버튼 누르면 즉시 시작)
   - **밤 (방어전)**: 60초 (Day 1~4), 120초 (Day 5 Final)
   - **한 판(1 Run) 총 소요 시간**: 약 **8분 ~ 12분** (초간단 미니 프로젝트에 가장 몰입감 높은 호흡)
