# 《5일 뒤 마왕》 0.2 버전 변경사항

> 기준일: 2026-08-10
> 비교 기준: 0.1 명세 및 기존 Phaser 로컬 수직 슬라이스
> 목적: 실제 구현·부분 구현과 남은 릴리스 작업을 구분해 추적

## 1. 요약

0.2의 핵심 변화는 “멀티플레이 연결 기능이 붙은 로컬 게임”에서 “Colyseus가 기본 게임 상태를 소유하는 서버 권위 vertical slice”로의 전환이다. GameCore world부터 기본 전투·AI·경제·성장·이동·승패, PartyRoom state/command, RoomGameScene snapshot 렌더까지 연결됐다. 스킬·부활·건설·고급 boss pattern과 실제 3-client/배포 검증은 아직 완료되지 않았다.

## 3. 현재 구현·연결 완료

### 3.1 백엔드·Room lifecycle

- Next.js Node 서버, Colyseus game-server, PostgreSQL/Drizzle workspace
- 서버 세션, CSRF, 90초 RS256 game-ticket JWT와 공개 guest route
- `solo` 정확히1 / `coop` 정확히3, ready 후 lock, 20Hz GameCore
- 서버 20초 reconnect와 client 18초 deadline, 최대 Room 35분
- 새 활성 session이 이전 예약 reconnect보다 우선하며 늦은 중복 연결은 `DUPLICATE_LOGIN`으로 닫는 race 보호
- 종료 결과 persistence Promise 직렬화와 최대 3회 bounded retry(회당 3초 timeout, 250/750ms backoff); 최종 실패해도 Room disconnect 진행
- match와 match_players transaction, 클라이언트 결과 POST 거부
- protocol strict Zod, 4KiB, 초당30개, 모든 명령의 session별 공통 단조 `seq`

### 3.2 protocol v2 명령 처리

- `partyMode`: `solo | coop`
- strict command envelope와 v2 version 검증
- 추가 명령:
  - `player.interact`
  - `travel.request`
  - `recall.request`
  - `equipment.equip`
- 기존 명령 유지·강화:
  - `player.input`, `skill.cast`
  - `build.place`, `build.upgrade`
  - `upgrade.choose`, `room.ready`

서버 의미 처리가 연결된 명령은 ready, input 이동/aim, interact, travel, recall, upgrade, equipment다. skill과 build는 schema가 있어도 각각 `SKILL_NOT_READY`, `BUILD_NOT_READY`로 거부한다.

### 3.3 PartyRoom state와 privacy

다음 Schema가 추가 또는 확장됐다.

- Player: `roomId`, `alive`, 장비 요약, 개인 증강 draft
- Room/door: 구역·그리드 좌표·종류·발견·클리어·연결
- Enemy: 행동 유형·생성 방·target·HP
- Waypoint: 활성·필요/점유 인원·5초 진행률
- Structure: 방·그리드·레벨·HP·소유자 schema만 존재하며 현재 map은 비어 있음
- Drop: 아이템·슬롯·희귀도·옵션 수·수령 여부
- Root: seed, currentZone, teamLevel/XP, entity maps

PartyRoom은 GameCore의 발견 room/door/enemy/waypoint, player 장비·통계, 개인 draft/drop을 실제로 동기화한다. draft와 drop은 `StateView`로 소유 사용자에게만 공개한다.

### 3.4 `game-core` 0.2 실제 시뮬레이션

`packages/game-core/src/v02` 규칙은 root `GameCore`와 PartyRoom에 연결됐다.

- 브라우저·Phaser 비의존 seed PRNG
- 결정론적 3구역 맵 생성과 invariant validator
- room-local 이동과 연결 door 전환
- 원거리60°/근접110° 자동 공격, 정적/히든 반격 AI와 밤 침공/base 피해
- 발견 자원 방 +1골드/5초, 정적 prototype30/full90초 리스폰
- 연결·생존 사용자 전원 5초 waypoint 이동과 같은 정족수의 recall
- gate 해금, 격리 boss room, 기본 boss HP·처치 승리
- Legendary80/Mythic20 개인 히든 장비, 상위 장비 자동 교체와 소유권 장착
- 팀 XP·레벨30·개인 결정론적 3-choice draft와 10/20/30 전직

자동 검증:

- 맵 1,000 run seed × 3구역 property test
- 드롭 20,000회 분포·경계·파티 순서 독립 test
- 3클래스 × 250 경로 × 레벨2~30 draft test
- bounded persistence retry/timeout과 duplicate reconnect race test

### 3.5 `RoomGameScene` network 연결

- `createGame.ts`의 현재 실행 scene은 `RoomGameScene`이다.
- network update는 server snapshot을 UI에 방출한 뒤 즉시 return하며 로컬 session·이동·전투·AI·경제를 실행하지 않는다.
- server room/door, 같은 방 player/enemy, owner-only drop, 개인 draft/equipment, teamPower·실시간 통계, 실제 waypoint 목적지·정족수를 장면/HUD에 반영한다.
- owner-only drop은 snapshot에서 현재 방 sprite로 표시하고, 사용자가 클릭하면 `equipment.equip` 교체 요청을 전송하며 750ms 중복 방지를 적용한다.
- travel/recall/interact/upgrade는 Colyseus command로 전달한다.
- transport는 최초 snapshot, 후속 patch, 서버 20초 예약 안의 client 18초 reconnect deadline과 result overlay 경계를 연결한다.

## 4. 실제 남은 작업

초기 “통합 대기” 1~10의 world·room 이동·자동 공격·AI·리스폰·자원·waypoint·boss·장비·성장 항목은 완료돼 이 목록에서 제거했다. 남은 범위는 다음과 같다.

1. network Q/E 스킬과 Space 회피, 개별 플레이어 부활
2. build validator와 structure 배치·강화·비용·충돌·경로 lifecycle
3. 장비 비교·확인·분해 UI와 특수 옵션 효과
4. 서버 공격·피격·투사체 event의 Phaser 이펙트
5. boss 탄막·장판·소환·광폭화와 히든 원거리 패턴
6. 중앙 waypoint 봉인 발판 협동 이벤트의 최종 선택과 구현
7. 세 브라우저 room 분산·waypoint·reconnect·StateView privacy·결과 저장 E2E
8. 공개 guest abuse rate limit·만료 row cleanup
9. 실제 배포 URL 신규 사용자 완주 smoke와 운영 관측

## 5. network 실행 경로에서 폐기한 규칙

- 기존 로컬 `GameScene`의 AI 동료 생성과 자동 사격 경로는 제거하고, `RoomGameScene`을 단일 실행 장면으로 유지
- HUD의 `BOT` 파티원 표시
- 3/6/9 전직 조건
- `vitality`, `armor`, `mobility`
- B키 또는 버튼만으로 즉시 상태를 바꾸는 로컬 귀환
- 날짜와 게이트 카운트만 확인하는 로컬 보스 입장
- 히든 처치 시 공격력 +2 직접 지급
- 클라이언트 단독 HP·골드·XP·승패 판정
- LocalTransport/D1을 현재 아키텍처로 설명하는 문서 표현

## 6. 결정된 기본값

- 솔로 1명 / 협동 정확히 3명
- 웨이포인트 정족수: `connected && alive` 실제 사용자 전원
- 웨이포인트 유지 시간: 5초
- 개인 히든 드롭: Legendary80% / Mythic20%
- 자동 조준: 원거리60° / 근접110°
- 자원 생산: 해금 방당 +1 팀 골드/5초
- 정적 리스폰: prototype30초 / full90초
- 서버 클래스·베이스 테이블을 단일 권위 원본으로 사용
- 공격속도: `interval / (1 + 증강 보너스 + 장비 보너스)`, 최소 0.12초
- 장비 100% 임시값: weapon 공격 +20, armor HP +80/방어 +8, accessory 공격속도 +30%
- 귀환: 활성 waypoint에서 같은 전원 5초 점유 후 zone1 base
- 공개 테스트 기본 경로: PostgreSQL guest session + 90초 game-ticket
