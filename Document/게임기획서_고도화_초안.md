# 프로젝트 가칭: 《5일 뒤 마왕》 게임 기획서

> 문서 상태: MVP 제작용 초안 v0.1  
> 목표 플랫폼: PC 웹 브라우저  
> 목표 개발 기간: 2~3일  
> 핵심 기술 후보: Phaser 3, Node.js, Colyseus

## 1. 게임 개요

마왕은 5일 뒤 왕국을 쓸어버리겠다고 선언했다. 문제는 오늘 소집된 용사 셋이 전부 신참이라는 것. 플레이어들은 낮에는 위험 지역을 개척해 힘과 자원을 얻고, 밤에는 몰려오는 마물로부터 베이스캠프를 지켜야 한다. 제한 시간 안에 전력을 완성해 마왕을 쓰러뜨리면 승리한다.

| 항목 | 내용 |
|---|---|
| 장르 | 3인 협동 로그라이트 디펜스 액션 RPG |
| 플레이 인원 | 1~3인, 3인 권장 |
| 세션 길이 | 약 25분, 개발용 단축 모드 8~10분 |
| 시점 | 탑다운 2D |
| 핵심 감정 | 시간 압박 속 역할 분담, 위험을 감수한 성장, 마지막 공동 보스전 |
| 승리 조건 | 5일차 종료 전 마왕 처치 |
| 패배 조건 | 베이스캠프 체력 0 또는 5일차 종료 시 마왕 생존 |

### 엘리베이터 피치

“낮에는 욕심내서 멀리 원정하고, 밤에는 누가 돌아가 기지를 지킬지 결정하는 25분짜리 협동 로그라이트.”

## 2. 디자인 원칙

1. **탐험과 방어는 항상 충돌한다.** 더 멀리 갈수록 강해지지만 기지는 더 위험해진다.
2. **혼자 강해지는 것보다 팀이 판단하는 과정이 중요하다.** 공용 골드와 밤의 역할 배분이 대화를 만든다.
3. **랜덤은 계획을 바꾸되 승리를 막지 않는다.** 필수 성장 수단과 이동 경로는 매 세션 보장한다.
4. **모든 클래스가 공격의 재미를 가진다.** 전담 힐러 없이 공격 방식과 팀 기여 방식만 다르게 만든다.
5. **25분의 모든 투자는 보스전에서 의미가 있어야 한다.** 탐험·시설·빌드가 최종전에 직접 연결된다.

## 3. 핵심 플레이 루프

### 세션 루프

1. 로비에서 클래스와 닉네임을 선택한다.
2. 낮에 방을 탐색하고 정적 몬스터를 처치한다.
3. 자원과 레벨업 특성을 얻고 게이트를 파괴한다.
4. 공용 골드로 기지 시설을 건설하거나 강화한다.
5. 밤에 웨이브를 방어한다. 일부는 전선을 유지할 수 있지만 위험이 커진다.
6. 하루 정산 후 다음 구역을 개방한다.
7. 4일차부터 마왕에게 조기 도전하거나 더 성장한다.
8. 마왕 처치 또는 제한 시간 종료로 세션을 마친다.

### 순간 플레이 루프

`이동 → 조준/공격 → 위험 회피 → 전리품 회수 → 다음 방 또는 귀환 선택`

## 4. 세션 구조

### 시간 구성

| 구간 | 기본 시간 | 역할 |
|---|---:|---|
| 낮 | 210초 | 탐험, 게이트 공략, 채집, 건설 |
| 밤 | 75초 | 강화 웨이브 방어, 잔류 탐험의 위험 감수 |
| 정산 | 15초 | 부활, 시설 수리, 다음 날 안내 |
| 하루 | 300초 | 총 5분 |
| 전체 | 25분 | 5일, 보스전 포함 |

보스방에 입장하면 일차 타이머는 계속 흐른다. 5일차 밤 종료까지 마왕을 처치하지 못하면 패배한다.

### 일차별 의도

| 일차 | 주요 구역 | 플레이 목표 | 새 압박 요소 |
|---|---|---|---|
| 1일차 | 1구역 초원 | 조작 학습, 첫 게이트, 첫 시설 | 느린 근접 웨이브 |
| 2일차 | 2구역 오염 숲 | 클래스 빌드 형성, 웨이포인트 | 원거리 적 추가 |
| 3일차 | 3구역 마왕성 외곽 | 고급 보상, 중간보스 | 방어 시설을 노리는 적 |
| 4일차 | 전 구역 | 부족한 성장 보완, 조기 보스 가능 | 정예 웨이브 |
| 5일차 | 보스방 | 최종 결전 | 지속 웨이브와 시간 제한 |

## 5. 맵과 진행

### 공간 구조

- 전체 맵은 좌측 하단 베이스에서 우측 상단 보스방으로 상승하는 3개 구역이다.
- 각 구역은 전투방, 자원방, 게이트방, 이벤트방을 격자에 연결한다.
- 화면 전환형 방 구조를 기본으로 하되, 멀티플레이어가 서로 다른 방에 있을 수 있다.
- 다음 구역은 해당 구역의 게이트방을 정리하면 개방된다.

### 안전한 절차 생성 규칙

완전 무작위 좌표 생성 대신 검증된 방 템플릿과 연결 규칙을 사용한다.

- 베이스에서 각 구역 게이트까지 최소 한 개의 유효 경로를 보장한다.
- 구역마다 게이트방 1개, 웨이포인트 1개, 회복 또는 보급 방 1개를 보장한다.
- 필수 경로의 전투력 요구치가 해당 시점 기대 전투력을 넘지 않도록 방 등급을 제한한다.
- 히든 방은 필수 경로에서 벗어난 가지에만 생성한다.
- 동일 시드는 동일 맵과 보상군을 생성해 버그를 재현할 수 있게 한다.

### 방 유형

| 방 | 주요 행동 | 보상 |
|---|---|---|
| 일반 전투방 | 정적 몬스터 처치 | 경험치, 소량 골드 |
| 자원방 | 채집 중 습격 대응 | 공용 골드 |
| 게이트방 | 중간보스와 게이트 파괴 | 구역 개방, 큰 보상 |
| 이벤트방 | 위험/보상 선택 | 회복, 특성 교체, 골드 |
| 히든방 | 강적 또는 퍼즐 | 희귀 특성 |
| 웨이포인트방 | 장치 활성화 | 빠른 이동 해금 |

## 6. 전투 시스템

### 기본 조작안

| 입력 | 기능 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 | 기본 공격 |
| Q / E | 클래스 스킬 |
| Space | 회피 또는 이동기 |
| F | 상호작용·건설·부활 지원 |
| B | 베이스 귀환 채널링 |

- 귀환은 3초 동안 피해를 받지 않아야 완료된다.
- 피격 시 짧은 무적 시간을 두어 다단 피격 급사를 방지한다.
- 쓰러진 동료를 일정 시간 내 구조할 수 있고, 실패하면 베이스에서 부활한다.

### 사망 규칙

- 사망 시 개인이 운반하던 공용 골드의 30%를 해당 위치에 드롭한다.
- 5초 후 베이스에서 부활하며, 드롭 자원은 누구나 회수할 수 있다.
- 반복 사망의 좌절을 줄이기 위해 장비와 레벨은 잃지 않는다.

## 7. 클래스

MVP에서는 차별화가 큰 3종을 우선 구현한다. 검사와 마법사는 후속 확장으로 둔다.

| 클래스 | 전투 리듬 | 기본 공격 | Q 스킬 | E 스킬 | 팀 기여 |
|---|---|---|---|---|---|
| 파이터 | 근접 연계와 버티기 | 3타 콤보 | 전방 충격파 | 돌진 강타 | 적 밀치기, 전선 유지 |
| 궁수 | 거리·각도 관리 | 빠른 화살 | 관통 사격 | 화살비 | 길목 광역 처리 |
| 마법사 | 느리지만 큰 범위 피해 | 마력탄 | 폭발 룬 | 순간이동 | 게이트·보스 폭딜 |
| 검사(확장) | 패링 후 반격 | 검격 | 패링 | 회전베기 | 정예 적 대응 |
| 도적(확장) | 후방·치명타 | 단검 투척 | 그림자 이동 | 독 폭발 | 고가치 표적 암살 |

전담 회복 클래스는 두지 않는다. 회복은 소모품, 이벤트방, 시설로 제공하며 모든 클래스는 공격과 생존 수단을 가진다.

## 8. 성장과 로그라이트

### 세션 내 성장

- 몬스터 처치로 개인 경험치를 얻는다.
- 레벨업 시 무작위 특성 3개 중 1개를 선택한다.
- 선택지는 클래스 전용 2개와 공용 1개를 기본으로 한다.
- 동일 특성 중첩은 최대 3단계로 제한해 효과를 읽기 쉽게 한다.

특성 예시:

- 공용: 이동 속도 증가, 최대 체력 증가, 처치 시 회복, 시설 주변 공격력 증가
- 파이터: 콤보 범위 증가, 충격파 2회, 돌진 재사용 대기시간 감소
- 궁수: 투사체 추가, 관통 횟수 증가, 화살비 지속시간 증가
- 마법사: 폭발 반경 증가, 상태 이상 부여, 룬 연쇄 폭발

### 세션 외 성장

MVP에서는 결과 화면에 해금 포인트만 기록하거나 로컬 저장한다. 확장 버전에서는 포인트로 신규 특성·시작 유물·외형을 해금한다. 영구 공격력 같은 직접 수치 강화는 작게 제한해 신규 플레이어와의 격차를 줄인다.

## 9. 자원과 타이쿤 시스템

### 자원 구조

| 자원 | 소유 | 획득 | 사용 |
|---|---|---|---|
| 경험치 | 개인 | 전투 기여·근접 공유 | 개인 레벨업 |
| 골드 | 팀 공용 | 전투, 채집, 이벤트 | 건설, 업그레이드, 수리 |
| 특성 | 개인 | 레벨업, 희귀 보상 | 전투 빌드 구성 |

골드는 획득 즉시 팀 금고로 들어가되, 사망 손실을 위해 탐험 중 획득분은 귀환 또는 웨이포인트 도달 전까지 ‘운반 중’으로 표시한다.

### 시설

자유 배치 대신 베이스 주변 지정 슬롯을 사용해 충돌·경로 탐색·네트워크 복잡도를 줄인다.

| 시설 | 역할 | 1레벨 효과 | 업그레이드 방향 |
|---|---|---|---|
| 포탑 | 지속 공격 | 가장 가까운 적 공격 | 피해·사거리 증가 |
| 장벽 | 진로 지연 | 적 이동 차단, 자체 체력 | 체력·가시 피해 증가 |
| 치유 모닥불 | 회복 지원 | 주변 플레이어 서서히 회복 | 회복량·범위 증가 |

MVP 우선순위는 포탑과 장벽이며, 모닥불은 시간이 허용될 때 추가한다. 시설만으로 밤을 완전히 해결할 수 없고 플레이어의 개입 시간을 벌어주는 수준으로 조정한다.

## 10. 적과 웨이브

### 적 분류

| 분류 | 행동 | 목적 |
|---|---|---|
| 정적 일반몹 | 방 내부에서 플레이어 공격 | 탐험 전투의 기본 |
| 정적 중간보스 | 게이트를 수호 | 구역 진척 검증 |
| 정적 히든몹 | 강한 패턴과 높은 체력 | 고위험 폭발 성장 |
| 동적 돌격병 | 플레이어를 통과해 기지로 이동 | 방어 압박 |
| 동적 사수 | 기지 또는 시설을 원거리 공격 | 우선 처치 유도 |
| 동적 파괴자 | 시설을 우선 공격 | 건설 투자 위협 |

동적 몬스터는 플레이어와 충돌하지 않아 길막을 피하지만, 플레이어의 공격과 군중 제어에는 영향을 받는다.

### 난이도 곡선

- 낮에는 게이트가 낮은 빈도로 돌격병을 생성한다.
- 밤에는 스폰 간격이 짧아지고 일차별 신규 적이 추가된다.
- 단순 체력 배율보다 조합과 진입 방향을 늘려 난이도를 높인다.
- 플레이 인원에 따라 적 체력과 수를 조정하되, 보스 패턴 속도는 유지한다.

## 11. 보스전

### 마왕 콘셉트

마왕은 방 중앙의 제단에 고정되어 탄막과 바닥 패턴으로 공간을 통제한다. 플레이어는 각자 완성한 빌드와 이동기를 활용하면서 소환물도 처리해야 한다.

### 3페이즈 예시

1. **선고:** 부채꼴 탄막과 예고형 원형 장판. 기본 회피 학습을 검증한다.
2. **침공:** 네 방향에 소환 포털을 열어 기지 웨이브와 유사한 적을 부른다. 광역 처리와 표적 분담을 검증한다.
3. **5일의 끝:** 체력 30% 이하에서 장판 안전지대가 줄고 탄막 속도가 증가한다. 짧은 화력 집중 구간을 만든다.

4일차부터 베이스의 포털에서 다수결 투표로 입장할 수 있다. 조기 도전은 추가 결과 점수를 주지만 필수는 아니다.

## 12. 멀티플레이 규칙

- 방장은 세션 시작과 맵 시드를 결정한다.
- 서버가 플레이어 위치 검증, 적 체력, 드롭, 골드, 일차 타이머, 승패를 관리한다.
- 클라이언트는 입력과 연출을 담당하고 위치를 보간한다.
- 공용 골드 사용은 즉시 반영하며 구매자 이름을 짧게 표시한다.
- 플레이어 간 충돌과 아군 피해는 없다.
- MVP에서는 진행 중 재접속과 중도 참가를 보장하지 않는다.

싱글·2인 시에는 적 체력과 스폰 수를 낮춘다. 빈 슬롯을 AI로 대체하는 기능은 MVP에서 제외한다.

## 13. UI/UX

### 상시 HUD

- 상단 중앙: 현재 일차, 낮/밤, 남은 시간
- 좌측 상단: 팀원 체력, 클래스, 거리·쓰러짐 상태
- 우측 상단: 미니맵, 게이트·웨이포인트·베이스 표시
- 좌측 하단: 개인 체력과 경험치
- 하단 중앙: 기본 공격, Q/E/회피 재사용 대기시간
- 우측 하단: 팀 골드, 운반 중 골드, 베이스 체력

### 중요 알림

- 밤 30초 전 귀환 경고
- 베이스 체력 50%·20% 경고
- 게이트 파괴와 다음 구역 개방
- 팀원의 보스 입장 투표
- 웨이포인트 해금과 귀환 가능 상태

## 14. 아트와 사운드 방향

- 16px 또는 32px 타일 기반 도트 그래픽을 사용한다.
- 1구역은 초록·노랑, 2구역은 탁한 청록·보라, 3구역은 보라·검정으로 위험도를 표현한다.
- 플레이어 캐릭터는 서브컬처풍 실루엣과 클래스별 포인트 컬러를 사용한다.
- 적 투사체, 위험 장판, 아군 스킬은 색상과 외곽선을 분리해 전투 가독성을 우선한다.
- 낮에는 경쾌한 탐험 음악, 밤에는 같은 테마의 빠른 변주를 사용해 페이즈 전환을 알린다.

## 15. 기술 설계 초안

### 클라이언트

- Phaser 3 씬: Boot, Lobby, World, Result
- 타일맵·방 템플릿, 입력, 카메라, UI, 이펙트 담당
- 공통 엔티티 데이터는 서버 상태를 렌더링하고 보간

### 서버

- Node.js + Colyseus 방 1개가 세션 1개를 담당
- 서버 틱에서 일차 타이머, 적 AI, 스폰, 피해 판정, 승패 처리
- 맵 시드와 방 템플릿 ID만 전송해 초기 상태 크기를 제한

### 저장

- MVP: 닉네임·설정·해금 포인트를 브라우저 로컬 저장
- 확장: 계정, 전적, 해금, 방명록을 PostgreSQL에 저장

## 16. 제작 범위와 일정

### MVP 완료 정의

세 명이 같은 방에 접속해 5일의 낮/밤을 경험하고, 탐험으로 얻은 자원을 시설과 개인 성장에 사용하며, 기지를 지킨 뒤 마왕을 처치하거나 패배할 수 있다.

### 3일 제작안

| 일차 | 목표 | 산출물 |
|---|---|---|
| 1일차 | 수직 슬라이스 | 접속, 이동·공격, 방 1개, 적, 기지, 타이머 |
| 2일차 | 전체 루프 | 3구역, 게이트, 골드·건설, 낮/밤, 클래스 3종 |
| 3일차 | 결승과 안정화 | 보스, 승패, 밸런스, UI, 배포·시연 점검 |

### 컷 순서

일정이 밀리면 `DB/로그인 → 방명록 → 히든몹 → 4·5번째 클래스 → 이벤트방 → 시설 3종째` 순서로 제외한다. 낮/밤 선택, 게이트, 기지 방어, 보스는 핵심이므로 유지한다.

## 17. 초기 밸런스 기준

정확한 수치는 플레이테스트로 조정하되 다음 목표를 사용한다.

- 첫 플레이에서도 1구역 게이트는 1일차 안에 발견·파괴할 수 있다.
- 적정 성장 팀은 밤 웨이브의 70~80%를 시설로 지연하고 직접 마무리한다.
- 3일차 종료 시 팀은 최종 보스 요구 전투력의 약 70%에 도달한다.
- 4일차 조기 보스 성공률은 숙련 팀 기준 20~30%를 목표로 한다.
- 5일차 보스는 적정 빌드 팀이 제한 시간 20~40초를 남기고 처치하도록 조정한다.
- 히든몹 보상은 강력하지만 필수는 아니며, 실패가 곧 세션 패배가 되지 않게 한다.

## 18. 플레이테스트 체크리스트

1. 밤이 오기 전 누가 귀환할지 실제 대화가 발생하는가?
2. 기지 방어 담당자도 조작과 성장의 재미를 느끼는가?
3. 공용 골드 사용이 갈등보다 전략적 토론을 만드는가?
4. 맵 시드와 관계없이 필요한 성장량을 확보할 수 있는가?
5. 다른 방에 있는 팀원의 위기와 목표를 HUD만으로 이해할 수 있는가?
6. 세 클래스의 공격 거리, 이동 방식, 강점이 첫 1분 안에 구분되는가?
7. 보스 패턴 사망이 네트워크 지연이 아니라 자신의 판단 결과로 느껴지는가?
8. 패배 후 원인과 다음 시도에서 바꿀 선택이 명확한가?

## 19. 오픈 이슈

- 실제 시연이 항상 3인인지, 1인 완주도 필수인지
- 수동 조준과 자동 조준 중 최종 조작 방식
- 시설 구매 권한과 공용 골드 분쟁 방지 규칙
- 4일차 보스 실패 후 후퇴·재도전 허용 여부
- 메타 성장의 저장 방식과 회원 기능의 발표 우선순위
- 모바일 지원, 배포 대상, 동시 접속 목표

이 항목들이 확정되면 클래스 수치표, 적·웨이브 스폰표, 방 템플릿 목록, 네트워크 상태 스키마를 다음 단계 산출물로 작성한다.
