# 0.1 버전 밸런스 데이터 테이블

> 이 파일은 **사람이 읽고 추후 밸런스를 조절**하기 위한 데이터 테이블입니다.
> 값은 현재 기준이므로 수정 시 코드 구현과 동기화해야 합니다.

---

## 1. 장비 레어도

| 레어도 | 기본 스탯 배율 | 특수 옵션 수 |
|---|---|---|
| 노말 (Normal) | 20% | 0 |
| 레어 (Rare) | 40% | 0 |
| 에픽 (Epic) | 60% | 1 |
| 레전더리 (Legendary) | 80% | 0 |
| 신화 (Mythic) | 100% | 2 |

### 장비 슬롯별 제공 스탯

| 슬롯 | 제공 스탯 |
|---|---|
| 무기 | 공격력 |
| 방어구 | 체력 + 방어력 |
| 장신구 | 공격속도 |

> 특수 옵션 풀(pool) 및 구체적 수치(예: 공격력+5 등)는 아직 미정. 아래에 후보 추가.

---

## 2. 증강 (레벨업 선택지)

> **공격 관련에 한정.** 체력/방어력/이동속도는 제외(장비로 결정).
> 기존 `vitality`, `armor`, `mobility`는 제거 대상.

| ID | 이름 | 효과 | 태그 | 최대 중첩 | 비고 |
|---|---|---|---|---|---|
| power | 무모한 연마 | 공격력 +3 | 공용 | 4 | |
| haste | 신속의 문장 | 자동 공격 속도 +12% | 공용 | 4 | |
| multishot | 쌍둥이 별 | 투사체 +1 또는 근접 범위 +20% | 공용 | 2 | |
| skill-power | 불안정한 마력 | 스킬 위력 +22% | 공용 | 3 | |
| swordsman-blade | 검기 개방 | 검격이 짧은 검기를 발사 | 전직 | 1 | |
| swordsman-execution | 처형자 | 체력 30% 이하 적 피해 +60% | 검사 | 1 | |
| archer-volley | 탄막 사수 | 자동 공격 부채꼴 추가 발사 | 전직 | 1 | |
| archer-sniper | 명사수 | 먼 적 피해 최대 +55% | 궁수 | 1 | |
| mage-nova | 파괴술사 | 마력탄/룬 폭발 범위 +55% | 전직 | 1 | |
| mage-tempo | 시공술사 | 스킬 재사용 -25% | 마법사 | 1 | |

> **증강 개수가 부족할 경우**, 다양한 게임의 증강 시스템을 레퍼런스로 참고해 공격 관련 선택지를 추가 제안할 것.

### 밀스톤(전직) 시점

| 레벨 | 내용 |
|---|---|
| 10 | 전직 선택 가능 (기존 3 대체) |
| 20 | 전직 선택 가능 (기존 6 대체) |
| 30 | 전직 선택 가능 (기존 9 대체) |

> 레벨 상한: **30**.

## 3. 구역별 방 구성 (15개/구역)

| 방 유형 | 개수 |
|---|---|
| 시작 방 (좌측 하단, 구역1은 베이스캠프) | 1 |
| 게이트 끝 방 (우측 상단) | 1 |
| 자원(채집) 방 | 4 |
| 정적 몬스터 방 | 4 |
| 빈 방 | 2 |
| 중앙 웨이포인트 방 | 1 |
| 히든 몬스터 방 | 2 |
| **합계** | **15** |

---

## 4. 구역/게이트/보스 관련

| 항목 | 값 |
|---|---|
| 그리드 | 구역당 5×5 = 25칸 (총 75칸) |
| 게이트 수 | 구역당 1개 (총 3개) |
| 웨이포인트 | 구역당 3개 (시작 / 게이트 파괴 후 끝 / 중앙) |
| 베이스 | 구역1 좌측 하단에 위치 |
| 최종 보스 | 구역3 게이트 파괴 후, 끝 방 웨이포인트에 모든 플레이어가 서면 진입 |

---

## 5. 최종 보스전

- 구역3 게이트 파괴 → 끝 방에 보스전 진입 웨이포인트 생성.
- 웨이포인트에 **실제 플레이어 전원**이 서 있어야 진입 가능.
